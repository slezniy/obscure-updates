# obscure Studio

Официальные сборки obscure Studio для Windows.

## Скачать

[Последняя версия Obscure.exe](https://github.com/slezniy/obscure-updates/releases/latest/download/Obscure.exe)

Начиная с версии 1.0.0 клиент проверяет подписанные обновления при запуске. Во время игры новые версии загружаются в фоне и устанавливаются при следующем запуске. Вручную проверить обновления можно в параметрах клиента.

Для доступа требуется лицензия владельца приложения. Лицензии привязаны к коду устройства (HWID).

В этом репозитории публикуются только готовые сборки и подписанное описание обновлений. Исходные тексты и закрытые ключи не публикуются.
